1. このページでできること1. What you can do

  • XAFS・HAXPES の標準試料スペクトルを、周期表の元素から探せます（国内の NIMS MDR と、International XAFS DB Portal（IXDB）を通じた各国の XAFS データベース）。
  • 見つけたスペクトルをその場でプロットして形を確かめ、必要なものだけをダウンロードできます。
  • 手元の測定データを読み込んで、XANES の形が似ている標準試料を探せます（XANES 類似検索）。

スペクトルの規格化・類似度の評価・文献値の表示は、いずれも既に論文や Athena などの既存ソフトで使われている手法をそのまま使っています。新しい解析手法を提案するものではなく、データベースの標準試料を探して比べる作業を手軽にするためのものです。

試作版です。表示内容は各データベースに登録されたメタデータに基づきます。データの利用条件・引用は各データベースの規定に従ってください。

  • Find XAFS and HAXPES reference spectra by element in the periodic table, from NIMS MDR (Japan) and the XAFS databases worldwide linked by the International XAFS DB Portal (IXDB).
  • Plot a spectrum on the page to check its shape, and download only what you need.
  • Load your own data and find reference samples with similar XANES (XANES matching).

Normalization, similarity metrics and reference values all use methods already established in published work and existing software such as Athena. Nothing here is a new analysis method; the aim is to make finding and comparing database reference samples easier.

Prototype. Information shown is based on the metadata registered in each database. Follow each database's terms of use and citation rules.

3. 試料を探す3. Finding samples

  1. 上のタブを選びます。IXDB タブでは「データベース」、MDR タブでは「施設」で対象を絞れます。
  2. 周期表で元素をクリックします。色付きの元素が登録のある元素です（色のない元素も MDR タブでは検索できます）。
  3. 一覧が出たら、「試料名・組成式で絞り込み」（例：oxide、NiO）や吸収端・分光結晶・分類で絞り込みます。

IXDB タブでは、同じ物質（MatVoc の物質 ID）の記録をまとめ、物質名を日本語／英語で表示します。「関連」列から、その物質の COD（結晶構造）・Materials Project（XAS シミュレーション）・AtomWork へ移動できます。

  1. Choose a tab. Narrow the scope with "Database" (IXDB tab) or "Facility" (MDR tabs).
  2. Click an element in the periodic table. Highlighted elements have registered data (other elements can still be searched in the MDR tabs).
  3. Filter the list by sample name or formula (e.g. oxide, NiO), edge, crystal or category.

The IXDB tab groups records of the same material (MatVoc material ID) and shows Japanese/English names. The "Related" column links to COD (crystal structures), Materials Project (XAS simulations) and AtomWork for that material.

4. スペクトルを見る（プロット）4. Viewing spectra (Plot)

一覧の「データ」列の プロット を押すと、その場でスペクトルを表示します（広い画面では周期表の下、狭い画面では一覧の上）。表示中の行は色が付きます。

  • 生データ／バックグラウンド除去・規格化：生データでは、差し引く前縁・後縁の線（破線）と E0（一次微分の最大、赤の点線）も重ねます。規格化は簡易処理です。解析には Athena などで処理し直してください。
  • 全範囲／XANES 付近：吸収端の前後（E0−30〜+70 eV）を拡大します。
  • ファイル：繰り返し測定・リファレンス（箔）・TEY／PFY など複数のファイルがあるデータは切り替えられます。HAXPES は「領域」（wide・VB・各内殻）を切り替えます（横軸は結合エネルギーで右ほど小さい）。
  • 緑の破線：文献値です。XAFS は NIST X-ray Transition Energies（SRD 128）の吸収端エネルギー（金属の値。化合物では化学シフトの分だけ高エネルギー側にずれます）で、このデータの E0 との差も表示します。HAXPES は NIST XPS Database（SRD 20）の推奨値（ない準位は Elam らの表）の結合エネルギーです。
  • 拡大：画面いっぱいに大きく表示します。縮小 か Esc キーで戻ります（スマホの縦画面では出ません）。
  • プロット（準備中）：まだ取り込んでいないデータです（試作版のため一部のみ）。

Press Plot in the "Data" column to show the spectrum (under the periodic table on wide screens, above the list on narrow ones). The plotted row is highlighted.

  • Raw / Background-subtracted, normalized: the raw view also shows the pre- and post-edge lines (dashed) and E0 (maximum of the first derivative, red dotted). Normalization is simple; use Athena or similar for analysis.
  • Full range / XANES region: zooms to E0−30 to +70 eV.
  • File: switch between files of a dataset (repeated scans, reference foil, TEY/PFY). For HAXPES, switch the region (wide, VB, core levels); the axis is binding energy, decreasing to the right.
  • Green dashed lines: reference values. XAFS: edge energy from NIST X-ray Transition Energies (SRD 128) — the value for the metal; compounds shift to higher energy by the chemical shift — with the difference from the data's E0. HAXPES: binding energies from the NIST XPS Database (SRD 20) recommended values (Elam et al. for levels without one).
  • Enlarge: shows the plot as a large overlay; Shrink or Esc to return (not shown on phones in portrait).
  • Plot (in preparation): not imported yet (prototype: only part of the data).

5. ダウンロード・引用5. Download and citation

  • 一覧のチェックボックスで試料を選ぶと、下の「ダウンロード」にまとまります（タブや施設を切り替えても保持）。
  • 選択した試料を zip でダウンロード（MDR 分）：MDR から直接ダウンロードします。MDR の応答により 1 件 30 秒程度かかることがあります。
  • 選択リストを CSV 保存：DOI・URL の一覧を保存します。
  • 引用文をコピー：論文などで使う引用文（英語）をコピーします。
  • 海外のデータベースは「〇〇で開く」から各サイトへ移動してダウンロードしてください。
  • Tick samples in the list; they are collected under "Download" (kept when you switch tabs or facilities).
  • Download selected as zip (MDR records): downloads directly from MDR; each may take about 30 s.
  • Save selection as CSV: saves DOIs and URLs.
  • Copy citations: copies citations (in English) for papers.
  • For overseas databases, use "Open in …" and download from each site.

6. XANES 類似検索6. XANES matching

  1. 元素・吸収端：XANES 類似検索 タブで周期表から元素を選び、吸収端を選びます。必要なら「比較する対象」（DB・施設）と「分光結晶」で絞ります。
  2. 測定データ：テキストファイルを読み込みます。2 列（E・μ）、Athena、XDI、PF9809 形式の .dat に対応しています。列が多いときは、エネルギーの列と「その列／ln(A/B)／A/B」を選びます。エネルギーは eV（keV なら自動で換算）。
  3. エネルギー補正：施設やビームラインで校正の基準が違うため、ここが重要です。
    • 同じ条件で測ったリファレンス（その元素の金属箔など）があれば読み込みます。半値エネルギー（規格化 μ = 0.5）を DB の基準値に合わせます。PF9809 の .dat に I2 のリファレンスがあれば、それも使えます。
    • リファレンスがなければ、測定した施設を選ぶとその施設の代表的な補正量を使います。
    • 微調整のスライダーを動かすと、結果がすぐ更新されます。重ね描きを見ながら合わせてください。
  4. 比較する を押すと、似ている順に候補が並びます。行をクリックすると、測定データ（橙）と候補（青）を重ねて表示します（規格化 μ と一次微分を切り替え可）。

結果の見方

  • 総合：6 つの指標それぞれの順位の平均（小さいほど似ている）。見出しをクリックすると、その指標で並べ替えます。
  • Pearson・コサイン・Ruzicka（大きいほど似ている）：XANES 照合アルゴリズム ELSIE（Zheng et al., npj Comput. Mater. 2018）で使われた指標。
  • 微分 Pearson：一次微分の相関。ピークや肩の位置に敏感です。
  • Spearman：強度の大小関係だけを見る順位相関。
  • R 因子（小さいほど似ている）：Athena の線形結合フィットと同じ形。
  • DB 側の補正：DB のスペクトルを「個別」（同時測定のリファレンスで 1 件ずつ）、「施設」（施設の代表値）、「なし」のどれで補正したか。
  • 重なり：比較する範囲のうち両方にデータのある割合（60% 未満は比較しません）。範囲は「比較する範囲」で変えられます。

似ている順は参考です。物質の同定を保証するものではありません。比べる DB は取り込み済みのスペクトルだけです。測定データはブラウザの中だけで処理し、どこにも送信しません。

  1. Element and edge: in the XANES matching tab, select an element and an edge. Optionally narrow "Compare with" (database/facility) and the mono crystal.
  2. Your data: load a text file (2 columns E, μ; Athena; XDI; PF9809 .dat). With many columns, choose the energy column and "column / ln(A/B) / A/B". Energy in eV (keV is converted).
  3. Energy correction (important, since calibration differs between facilities):
    • If you have a reference (e.g. a metal foil of the element) measured under the same conditions, load it; its half-step energy (normalized μ = 0.5) is aligned with the database reference point. A reference in I2 of a PF9809 .dat can also be used.
    • Without one, choose the facility of your data to use its typical shift.
    • Move the fine adjustment slider; results update immediately. Watch the overlay while adjusting.
  4. Press Compare: candidates are listed, most similar first. Click a row to overlay your data (orange) and the candidate (blue); switch between normalized μ and first derivative.

Reading the results

  • Overall: mean rank over six metrics (smaller is more similar). Click a header to sort by that metric.
  • Pearson, cosine, Ruzicka (larger is more similar): metrics used in the ELSIE XANES matching algorithm (Zheng et al., npj Comput. Mater. 2018).
  • Derivative Pearson: correlation of first derivatives, sensitive to peak and shoulder positions.
  • Spearman: rank correlation using only the ordering of intensities.
  • R-factor (smaller is more similar): same form as in Athena's linear combination fitting.
  • DB alignment: whether the database spectrum was aligned with its own reference ("own ref."), the facility typical value ("facility"), or not ("none").
  • Overlap: share of the compared range where both have data (below 60% is not compared). Change the range with "Range compared".

The ranking is a guide and does not identify the material. Only imported spectra are compared. Your files are processed only in your browser and are not sent anywhere.

7. 関連情報7. Related resources

周期表の下の「関連情報」から、XAFS シミュレーション（Materials Project）、HAXPES スペクトル、結晶情報（COD。選択中の元素で検索するリンク付き）、状態図（CPDDB）、物性情報（AtomWork）へ移動できます。選択中の元素に HAXPES データがあれば、MDR（HAXPES）タブに切り替えるボタンも出ます。

"Related resources" under the periodic table links to XAFS simulations (Materials Project), HAXPES spectra, crystal structures (COD, with a search for the selected element), phase diagrams (CPDDB) and properties (AtomWork). If the selected element has HAXPES data, a button switches to the MDR (HAXPES) tab.

8. データの出典・更新日・ライセンス8. Data sources, dates and licenses

  • 検索ページの一番下に、データの作成日（IXDB 索引、XANES 類似検索の索引、NIST の文献値）と、プロット用スペクトルの取り込み状況（データベースごとの取り込み済み件数／全件数と最終取り込み日）を表示しています。
  • MDR などはブラウザから直接データを取得できないため、プロット用のスペクトルは事前に取り込んでいます（IHEP はその都度 IHEP の API から取得）。
  • ライセンスはプロットの下に表示しています（例：MDR は各データの表示に従う、LISA・CLS は CC BY 4.0、XASLIB はパブリックドメイン）。ESRF は規約で複製が禁止されているため、リンクのみです。FAME（SSHADE）はデータの取得にログインが必要なため、リンクのみです。
  • 論文などで使う際は、各データの DOI と各データベースの引用ルールに従ってください（ページ下部の案内、「引用文をコピー」も参照）。
  • The bottom of the search page shows the data dates (IXDB index, XANES matching index, NIST reference values) and the import status of the spectra for plotting (imported/total per database and last import date).
  • MDR and others cannot be read directly from the browser, so spectra for plotting are imported in advance (IHEP is fetched from its API each time).
  • Licenses are shown under each plot (e.g. MDR as stated per dataset, LISA and CLS CC BY 4.0, XASLIB public domain). ESRF terms prohibit reproduction, and FAME (SSHADE) requires a login, so both are link-only.
  • When using data in publications, cite each dataset's DOI and follow each database's citation rules (see the page footer and "Copy citations").

9. よくある質問9. FAQ

DOI を押してもページがなかなか開きません

MDR の応答が遅く、1 分近くかかることがあります。少し待ってください。

「プロット（準備中）」と出ます

そのデータのスペクトルはまだ取り込んでいません。取り込み状況はページ下部で確認できます。

類似検索で自分のファイルが読み込めません

数値の列が 2 列以上あるテキストファイルにしてください（コメント行は # で始める）。読み込めない形式があれば、管理者に知らせてください。

類似検索の結果が施設によって偏ります

エネルギー補正が合っていない可能性があります。リファレンスを読み込むか、微調整で重なりを見ながら合わせてください。「比較する対象」で施設を絞ると、校正の違いの影響を小さくできます。

The DOI page takes a long time to open

MDR can be slow (up to about a minute). Please wait.

"Plot (in preparation)" is shown

That spectrum has not been imported yet. The import status is at the bottom of the search page.

My file cannot be read in XANES matching

Use a text file with at least two numeric columns (comment lines starting with #). Please report formats that cannot be read.

Matching results are biased toward one facility

The energy correction may be off. Load a reference, or fine-tune while watching the overlay. Restricting "Compare with" to one facility reduces the effect of calibration differences.
